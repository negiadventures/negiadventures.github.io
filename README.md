# anirudhnegi.com / negiadventures.github.io

Personal portfolio. Next.js 16, React 19, Tailwind 4, MagicUI.

Static export (`output: "export"`), so it deploys identically to GitHub Pages
and Vercel. No server, no API routes.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in ./out
```

Content lives in `lib/data.ts`. Photos in `public/photos`, project shots in
`public/shots`.
