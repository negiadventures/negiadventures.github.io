About

Systems-focused engineer who turns complex workflows into reliable platforms.

For over eight years I've designed event-driven systems, data integration pipelines, and cloud infrastructure at GoFundMe, Genentech, SymphonyAI, and Mediaocean. Most of my work sits where correctness is expensive to retrofit: event schemas and delivery guarantees, graph and relational data models behind search and recommendation, and migrations that have to land while the business keeps running.

Independently I build and operate Utilix, a developer tool platform serving one shared registry across six surfaces, and Karyfy, a multi-service AI job-search platform. Both run on scheduled agents that extend them daily without supervision. The interesting problem there is not speed. Once implementation stops being the bottleneck, the quality of your specification and the guardrails around it become the whole game.

Impact highlights

Stories from the trenches of building at scale.

Modeling a domain as a graph

At GoFundMe I modeled the charity, fundraiser, and donation domain as a Neo4j property graph and built the sync pipeline that keeps it current. A graph store beat relational joins here because the traversals driving recommendations are exactly the ones joins make most expensive.

Event-driven integration at scale

Owned the architecture connecting GoFundMe's distributed fundraising services to Salesforce Nonprofit Cloud: event schema, delivery guarantees, retry and backoff policy, and a dead-letter strategy that holds data consistent under partial failure. It replaced a tightly coupled sync path that generated recurring manual reconciliation work.

Pipelines across millions of entities

Designed and led ETL spanning 1.8M+ charities and 6M+ fundraisers, with idempotency keys, checkpointing, and graceful degradation so runs resume mid-window without loss or duplication. Instrumented lag, error rate, and throughput so degradation surfaced before it reached consumers.

Ten hours to four

Cut Genentech's end-to-end Spring Batch runtime by 60 percent, from over ten hours to four, by profiling hot paths and restructuring chunk sizing, step parallelism, and reader-processor-writer I/O against memory and connection-pool limits.

Search that stays current

Re-architected the Algolia search-index sync at GoFundMe, taking a 10+ hour run down to 4 hours across millions of records, so the index finishes inside its operational window instead of overrunning it.

Migration in a regulated environment

Led a large-scale Salesforce to enterprise-database migration at Genentech, with integrity validation, reconciliation, idempotent execution, and rollback, so failed runs could be safely re-run without duplication or corruption.

Guardrails for autonomous agents

On Karyfy, work is partitioned by label. A scheduled agent implements and merges auto-safe issues behind a green-test gate, while anything touching auth, payments, secrets, DB migrations, or deploys is fenced off as needs-human. A test-integrity rule forbids weakening a test to force green; the agent reverts and reports blocked instead.

One specification, six surfaces

Utilix runs from a single shared tool registry feeding a web app, a REST API, a Node SDK, a Python SDK, an embeddable widget, and an MCP server. That design is what makes a daily agent safe to publish to npm and PyPI unattended, since one spec propagates everywhere rather than six hand-edits drifting apart.
